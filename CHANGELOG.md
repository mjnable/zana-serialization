# Changelog

All Zana packages share one version number and are released together. A release that did
not change this package is not listed.

## 2.0.0 — 2026-10-26

The final 2.0 release. No changes since 2.0.0-rc.1.

## 2.0.0-beta.1 — 2026-10-25

### Added

- `#[ErrorMessage]` sets the message of a hydration error.
- `SerializationServiceProvider`.

## 2.0.0-alpha.3 — 2026-10-24

First release of the 2.0 line. Convert objects to arrays and JSON, and hydrate typed objects from arrays and JSON through their constructors. No dependencies. Requires PHP 8.5 or later.

Documentation: [the serialization guide](https://github.com/mjnable/zana-docs/blob/main/guides/serialization.md).
